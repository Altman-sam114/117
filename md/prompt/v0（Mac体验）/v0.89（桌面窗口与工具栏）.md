# v0.89 桌面窗口与工具栏

## 版本分配依据
沿 v0.88 界面重构递增一个小版本；本轮聚焦 Mac Catalyst 桌面入口的窗口初始体验和状态可见性。

## 背景与目标
项目已有 Mac Catalyst target、独立统计窗口、菜单命令和最小窗口约束。本轮增加 1360×860 的默认窗口尺寸，并在 Mac 工具栏展示当前筛选结果数量，让首次打开和长时间写作更接近桌面工作台。

## 非目标
不改 JournalStore、JSON 格式、Markdown parser、编辑器 bridge、部署版本或 iOS 布局；不引入第三方依赖，不创建 PR，不启用子智能体。

## 架构依据与影响范围
修改 `MDJournalApp.swift` 的 Mac Catalyst WindowGroup scene 配置、`ContentView.swift` 的 Mac toolbar，以及既有 `MarkdownSnippetTests.swift` 的纯值窗口契约。

## 实现步骤
1. 保留 1120×720 最小内容尺寸，增加 1360×860 默认窗口尺寸。
2. 仅在 Mac Catalyst 条件编译下显示当前筛选结果数量和可访问性值。
3. 用契约测试锁定默认尺寸不小于最小尺寸。

## 本地轻量检查
运行 `git diff --check`、`xcrun swiftc -parse -parse-as-library $(rg --files -g '*.swift' MDJournal)`；不运行本机完整 build、模拟器或 UI 自动化。

## main 直推与云端验收
从最新 `origin/main` 在 `main` 上实现，提交并 push `origin/main`，由 GitHub Actions 同时重跑 iOS、Mac Catalyst 和 XCTest。云端结果须以最新 commit 对应 run/attempt/artifact 为准，artifact 未加密并含 manifest、JUnit、主日志和关键产物。

## 文档与风险
同步 README、`md/test/test.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`update_log.md`。默认尺寸和工具栏文案由平台 build 间接覆盖；真实窗口恢复、鼠标/触控板、VoiceOver 与性能仍需人工验收。

## 2026-10-13 接续与视觉复核修订

保留接续任务已有未提交改动，不开启子智能体。v0.88 起点已下载核对（run 36234465443、attempt 1、231/231 passed）；六张附件的视觉复核发现横屏正文空间过小、辅助字号工具栏密集且 UIKit 正文字号未跟随 SwiftUI 环境。

- 本轮补齐低高度（实际可用高度 <400pt）紧凑标题，模式切换与 Markdown 菜单共用一行，隐藏底部状态栏，收起详情时头部不超过 52pt/22%。普通高度保持原布局，辅助字号改用工具菜单。
- UITextView 字体配置显式消费 SwiftUI DynamicTypeSize，保留 rounded body、相同字体不重设和全部正文/选区/IME 同步规则。
- defaultSize 仅在 Catalyst 17+ 使用，旧版本回退现有窗口行为；不提高 deployment target。
- 新增低高度与字号契约测试，重跑原六张云端渲染图。预计 233 项，实际以最新 artifact 为准。
- C 步骤：当前线程以 gh auth login 后的授权下载最新 artifact，校验 SHA/run/attempt、四阶段、JUnit、日志、三份 xcresult、ZIP/digest、渲染图；不宣称独立 Agent C。
