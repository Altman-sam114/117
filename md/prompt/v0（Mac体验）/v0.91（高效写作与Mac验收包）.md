# v0.91 / 高效写作与 Mac 验收包

日期：2026-10-23。

## 授权、起点与轮次

用户最新要求“不多开子智能体”。已有子智能体已停止，后续方案、实现、main 推送和 artifact 核对均由当前线程串行完成，不标记为独立 A/B/C 验收。此要求优先于入口多 Agent 流程；云端编译继续。

v0.90 起点为 main 的 `7283b1e4116bd6c776019aa4ff772c97856567b0`，run `39806459795` attempt 1：四主阶段及图片导出成功，245 项 XCTest、11 张图片、588 个未加密 ZIP 文件和完整性已由当前线程核对。首次 run 的失败记录保留。

考虑 runner 每次排队约十分钟，将原候选 v0.91 性能与 v0.92 Mac 内部包合并为本轮，减少重复云端排队；两类验收门槛分别保留。版本仍为 v0.91，不提前称正式发布。

## 目标和非目标

- 在 JournalStore 同步维护按 ID 的紧凑正文展示投影：词数、小节数、可见性、有限摘录和仅用于显示的小节预览。
- 加载/新建派生一次，正文更新只重新派生变更 ID；相同正文、标题、分类、心情、日期更新复用；删除释放。不按 updatedAt、global revision 或全文哈希失效。
- ContentView、列表行、编辑器、统计 sheet/窗口显式消费同一缓存；不保留生产视图静默重新扫描正文的回退。
- 保留纯值旧 API 用于兼容和结果对照。统计继续 O(n) 元数据聚合，日历/时区/now 不进入正文缓存键，不宣称整体输入 O(1) 或帧率提升。
- 缓存不保留原文、完整 excerpt、section markdown、Markdown AST 或旧版本；单条展示摘录/标题限制为160个 Character 加省略号。
- 修正辅助字号分类菜单的过碎换行，保留44pt命中和原筛选状态。
- 新增可编辑的原生绘图应用图标、云端 universal Mac Catalyst Release `.app` 内部验收 ZIP，以及可追溯构建版本。
- 不更换 SwiftUI/Catalyst，不引入第三方库，不改 deployment、bundle ID、JSON、保存策略、parser、UITextView bridge、选区、IME 或快捷键语义。
- 不公证、不公开发布、不要求访问签名私钥；内部包使用 ad-hoc 签名并明确未公证。

## 影响范围与步骤

1. 新增 `JournalEntryBodyPresentation`，由现有 summary 临时派生后投影；Store 在 entries 发布前更新缓存，保证当前 entries 的每个 ID 都有匹配投影。
2. 概览/统计增加显式投影输入，生产视图强制传入；保留旧纯计算初始化入口供既有测试，不让生产默认调用它。
3. 列表/编辑器小节卡片仅渲染投影，原 Binding 继续即时写回 Store；统计窗口共享 Store 缓存。
4. 注入 presentation builder，用真实 Store 计数测试证明加载 N 次、单篇正文更新1次、元数据与筛选0次、新建1次、删除0次，以及缓存 ID 集随集合维护。
5. 验证 Unicode 摘录边界、投影与旧 summary 的词数/小节一致性、日历/时区/周变化的统计等价性、现有全部持久化/导航/输入/截图回归。
6. 新增独立只构建/打包脚本，云端 Release 明确 `ARCHS="arm64 x86_64" ONLY_ACTIVE_ARCH=NO CODE_SIGNING_ALLOWED=NO`，不启动 App；现有 Debug Run 脚本保持职责。
7. 图标用项目内原生绘图源码生成，保留生成源码和必要 PNG，配置 iOS/Mac AppIcon。图标风格为暖纸面、墨绿笔记本，避免文字缩小不可读。
8. 检查实际 `.app` Info.plist、执行位、全部 Mach-O 架构、Catalyst平台、图标、ad-hoc签名；用 ditto ZIP 保留执行权限，独立解压复核，并输出逐文件摘要、ZIP SHA-256、版本/commit/run/attempt。
9. CI 保留四主阶段、单设备串行测试、11图导出与超时，再新增 Release/打包独立 outcome、日志、结果包和机器可核对报告，失败使 workflow 失败；不上传 DerivedData。

## 轻量检查与 main 直推

遵循 AGENTS.md、md/test/test.md 的 diff、Swift parse、plist、YAML/内嵌 shell/Python 语法检查；图标生成属于资源创作，不运行项目、App、XCTest 或模拟器。本机 iOS 仍仅允许 FAC4325D 前缀的既有唯一模拟器，本轮不用。

确认 main、origin/main 与相关文件范围后提交并直推，不建分支/PR。远端含旧凭据时使用仅本命令 `remote.origin.pushurl` 的同仓库干净地址与已有 gh credential helper，不输出 token、不改全局认证。

同步 README、test、flow、flowchart 和更新日志，当前协作描述改为串行，历史独立 Agent 记录保留。

## 当前线程云端验收与停止条件

只下载最新 origin/main SHA 对应 run/attempt 的未加密 artifact；核对 manifest、各 outcome、JUnit、真实 XCTest 数、日志、三份现有 xcresult 和 Release结果、11图、digest、CRC、fresh extract 和逐文件哈希。

Mac 包另外核对 arm64+x86_64、版本、权限、图标和 ad-hoc 签名、ZIP内容与报告完全一致；不启动本地 App。未获得 Developer ID/公证和真实 Mac/IME/VoiceOver/性能实测前，明确只是内部验收包。

任一门槛失败只在本版本追加修复；连续同因 CI 失败、连续两轮无有效 diff、三轮同一阻塞、需要账号/权限/付费/人工决定或归属不明冲突时停止并如实记录。完成本轮有限范围后报告真实剩余发布门槛，不以旧artifact或静态图片冒充本轮验证。
