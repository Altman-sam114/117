## 一、双栏布局与命令状态

在 EntryEditorLayoutContract 保留 wideLayoutMinimumWidth = 820 作为头部宽度档位，新增 splitPreviewMinimumWidth = 1120 和 usesSplitPreview。
双栏条件精确为 detail width >=1120 且非 Accessibility；820 宽头部与双栏分离。旧 isWideEditorLayout 若保留，不得再当作双栏开关。

| detail 宽度 | 字号 | 紧凑横向头部 | 双栏工作区 |
| --- | --- | --- | --- |
| 819 | large | 否 | 否 |
| 820 / 1119 | large | 是 | 否 |
| 1120 / 1440 | large / xxxLarge | 是 | 是 |
| 820 / 1120 / 1440 | accessibility1...5 | 否 | 否 |

- 使用 GeometryReader 的实际 detail 宽度，不使用窗口宽度。默认最小窗口减理想 sidebar 为 1120-300=820，保持单栏；隐藏 sidebar 后可能满足双栏阈值，不作相反承诺。
- 双栏宽度含 Divider，两栏近似等分；净正文还须扣 padding，不声称每栏恰为 560。保留当前预览 padding/行宽上限和专注写作宽度。
- 工作区、previewToggleTitle、toolbar help/accessibilityLabel、togglePreviewVisibility、focusWriting 和 focused scene action 共用实际 usesSplitPreview。
- 旧 isWideLayoutActive 若保留，必须反映 split 工作区资格，不能反映 width>=820，也不能等同于右侧列可见性；隐藏右栏仍走双栏命令分支。
- 首次出现按真实 geometry/字号初始化，默认单栏 edit，不无条件聚焦。宽度和 Dynamic Type 变化走同一转移入口，不在 body 求值时 mutation。
- 引入最小非持久化纯转移策略供生产与测试共用，明确 mode、列偏好、focus；避免保留脱离显示事实的过期 compact mode。

跨阈值与命令必须满足：

1. 单栏编辑进入双栏：保持选区和焦点意图，沿用双栏列显示偏好；曾由专注写作隐藏的列不得仅因尺寸往返自动恢复。
2. 单栏预览进入双栏：显示预览列，即使旧列偏好隐藏；不自动请求正文焦点，合理归一化旧 compact mode。
3. 双栏收窄或改 Accessibility：正文有焦点时进入单栏编辑并保留选区/焦点意图；未聚焦且预览可见时进入单栏预览；列隐藏时进入单栏编辑。
4. 双栏隐藏预览、专注写作、聚焦正文、插入或缩进后，后续收窄不能复活过期 preview。双栏切列不无故清除正在使用的正文焦点。
5. 单栏进入预览 resign，Cmd-Option-P 返回编辑 focus，Picker 返回编辑 preserve；复用既有 EntryEditorFocusPolicy，不新增固定延时。
6. 纯布局转移不写正文、不调用 resetBodySelectionToEnd；该函数仍只随日记 ID 切换。非空 UTF-16 选区和 emoji 边界保持。
7. 优先保持正文控件结构身份；如仍存在重建，审查焦点 binding 回写和已有 bridge 请求门控。不能新建隐藏编辑器、复制正文状态或修改 bridge 掩盖问题。

## 二、单一 Render Snapshot 与 Inline 缓存

在 MarkdownPreviewView.swift 内增加小型 MarkdownPreviewInlineCache 和 render snapshot 值类型，使用单一 @Published snapshot 同时持有 document 与 cache。
保留 model.document 等只读兼容访问可以接受；禁止两个独立 @Published 发布 document/cache 产生瞬态错配。

```text
entryID + markdown + generation
  -> 首次立即 / 150ms trailing 调度
  -> accepts 门控 -> parseDocument 一次
  -> 收集渲染原文、去重、构建 inline cache
  -> 单一 render snapshot 发布
  -> body 捕获 snapshot，所有延迟子闭包只读该 snapshot
```

- body 开头读取同一份 snapshot，document、shouldUseSectionGroups、cache 从它派生；将 cache/snapshot 显式传给 blockView、sectionGroupView 和 ForEach/LazyVStack 子闭包。
- LazyVStack 的旧 block 闭包不得再读取 updateModel 最新缓存。即使新 document 已发布，旧闭包也必须用自己捕获的匹配快照。
- 初始化为空快照，不解析正文；首次 activate、切换日记和 deactivate 后再 activate 发布新匹配快照。等待 debounce 时保留上一份 document/cache。
- 旧任务必须先过 generation/entryID/正文/active 门控，被拒绝任务不得调用 parser、renderer 或改 snapshot；保留取消任务迟到也可验证的 scheduler。
- body、view initializer、blockView、sectionGroupView 和 lookup 不执行 Markdown 转换、触发字符扫描或惰性缓存填充。字体、accent、布局继续由视图修饰。
- 缓存按原始字符串精确键去重，不 trim/改大小写/摘要化；一份接受 document 内每个唯一原文最多转换一次，重复块和分组引用共享。
- 新 document 整体替换缓存，旧专有 key 不可命中；不累积历史文档。允许新文档重新转换其唯一文本，不要求跨文档复用。
- 收集 heading/paragraph/quote、unorderedList 字符串、orderedList/checklist 的 item.text；覆盖普通 blocks、intro 和 section blocks，可遍历并集去重，不再次调用 parser。
- group.title 保持现有原文 Text 语义；code、空代码占位、分割线、编号、勾选、删除线、空态及小节空内容提示保持，不送进新增 inline renderer。
- 保留 shouldParseInlineMarkdown 完整触发字符集和 inlineMarkdown 输出；plain 直接构造并缓存 AttributedString(text)，不调用 Markdown renderer。
- 默认 renderer 保持现有 try AttributedString(markdown: text) options/语义；注入最小 throwing renderer 用于计数/失败测试，失败缓存原文 AttributedString，重复查询不重试。
- lookup 应可观察未命中；合法渲染文本必须全部命中。不能用 miss 后重新 inline 解析掩盖遗漏；防御性原文回退也必须无解析、无 mutation。

- 失效：B 被 C 替代后迟到、切日记后迟到、deactivate 后迟到、重新激活后旧任务迟到，均断言 document/cache 不变且 parser/renderer 无额外调用。
- 集成审查：跨阈值隐藏预览仍执行 deactivate，重新显示读取新正文；只以纯测试和 diff 证明状态契约，不声称真实 first responder/IME 已验收。
