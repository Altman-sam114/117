## 背景与已确认问题

`MDJournal/Views/StatisticsDashboardView.swift` 中的 `SevenDayBarChart` 当前存在两个明确的自适应布局问题：

- 词数 `Text` 使用 `.frame(height: 14)`，整个图表使用 `.frame(height: 134)`。在 Accessibility Dynamic Type 下，语义字体增高但固定高度不允许内容自然扩展，可能产生垂直裁切。
- 七列始终放入可用宽度内并使用 `.frame(maxWidth: .infinity)` 等分。窄 iPhone 或较窄的 Mac Catalyst 统计窗口会持续压缩每列，辅助功能字号下尤其容易让数值与星期文本拥挤或截断。

现有统计数据和柱高语义本身正确：`JournalStatistics.lastSevenDays` 保持日期顺序，`maxDailyWordCount` 已预计算，`barHeight(for:)` 按最大词数缩放到 92pt 绘图区。本轮只改变视图布局适配，不重新定义统计口径。

## 目标

1. 建立 internal、无状态、无副作用、可由 `@testable import MDJournal` 访问的纯布局契约，建议命名 `SevenDayBarChartLayoutContract`。
2. 契约集中管理以下基线：
   - `plotHeight = 92`
   - `minimumValueLabelHeight = 14`
   - `minimumChartHeight = 134`
   - `accessibilityDayMinimumWidth = 56`；如实现证据表明其他正值更合理，可微调，但必须在代码、测试和文档中统一说明。
   - `usesHorizontalScrolling(for: DynamicTypeSize) -> Bool`；只有 Accessibility Dynamic Type 返回 `true`。
3. `SevenDayBarChart` 读取 `@Environment(\.dynamicTypeSize)`，由被测契约决定是否采用水平滚动。
4. 普通 Dynamic Type 保留当前七列在可用宽度内等分的布局与视觉。
5. Accessibility Dynamic Type 使用水平 `ScrollView`，七列采用稳定的最小或固定列宽，避免在窄 iPhone 与窄 Mac Catalyst 窗口内被强制压缩。
6. 词数 label 从固定高度改为最小高度，整个 chart 从固定高度改为最小高度，让语义文字自然增高；92pt plot 继续固定，维持柱高比例语义。
7. 新增纯契约测试，锁定普通字号不滚动、Accessibility 字号滚动及尺寸常量关系。
8. 将 workflow 版本更新为 `v0.71`，同步 README、核心流程、流程图、测试规范和更新日志，并由最新 `origin/main` 的 GitHub Actions 未加密 artifact 完成最终验收。

## 实现细节

### 1. 纯布局契约

在 `StatisticsDashboardView.swift` 中、`SevenDayBarChart` 附近新增默认 internal 的纯类型，推荐：

```swift
enum SevenDayBarChartLayoutContract {
    static let plotHeight: CGFloat = 92
    static let minimumValueLabelHeight: CGFloat = 14
    static let minimumChartHeight: CGFloat = 134
    static let accessibilityDayMinimumWidth: CGFloat = 56

    static func usesHorizontalScrolling(for dynamicTypeSize: DynamicTypeSize) -> Bool {
        dynamicTypeSize.isAccessibilitySize
    }
}
```

要求：

- 类型及被测成员为 internal，不显式写 `private` 或 `public`。
- 常量必须为正，`minimumChartHeight > plotHeight`。
- 滚动策略只根据传入的 `DynamicTypeSize` 决定；不得读取环境、设备型号、屏幕宽度或统计数据。
- 只允许 `.accessibility1` 至 `.accessibility5` 返回 `true`；`.xSmall` 至 `.xxxLarge` 均应返回 `false`。优先使用标准 `isAccessibilitySize`，不要手工维护脆弱的 raw value 或设备判断。
- 92、14、134 和辅助功能列宽由契约成为单一来源；视图中不得继续保留对应重复 magic number。

### 2. 环境字号与双布局策略

在 `SevenDayBarChart` 中增加：

```swift
@Environment(\.dynamicTypeSize) private var dynamicTypeSize
```

由 `SevenDayBarChartLayoutContract.usesHorizontalScrolling(for: dynamicTypeSize)` 派生当前策略：

- 返回 `false`：直接渲染现有 `HStack(alignment: .bottom, spacing: 9)`；每个 day column 保留 `.frame(maxWidth: .infinity)`，七列继续等分可用宽度；不得包裹水平 `ScrollView`。
- 返回 `true`：使用 `ScrollView(.horizontal, showsIndicators: false)` 包裹同一组七列；每个 day column 使用 `accessibilityDayMinimumWidth` 的稳定最小/固定宽度。推荐固定 `width`，或同时设置相同的 `minWidth`/`maxWidth`，确保窄窗口不会压缩；不得使用仍会被压缩到 56pt 以下的 flexible 宽度。
- 两条路径必须复用同一个 day column 内容或等价的局部 helper，避免以后两套柱图视觉和逻辑漂移。允许容器层有简短条件分支，不允许复制 `barHeight` 算法或日视图内容。
- 水平滚动仅限七日柱图，不得增加嵌套垂直滚动，不得影响外层统计看板已有 `ScrollView`。
- 保持从左到右的原 `days` 顺序，不反转、不排序、不截断，不新增分页或滚动定位状态。

实现时应优先采用清晰的 `@ViewBuilder` 容器/helper 或等价小范围结构，避免 `AnyView`、类型擦除、`GeometryReader`、`UIScreen.main.bounds`、布局测量状态和自定义 UIKit/AppKit bridge。

### 3. 高度与柱高语义

- 词数 `Text` 的 `.frame(height: 14)` 改为：

  ```swift
  .frame(minHeight: SevenDayBarChartLayoutContract.minimumValueLabelHeight)
  ```

- 图表根容器的 `.frame(height: 134)` 改为：

  ```swift
  .frame(minHeight: SevenDayBarChartLayoutContract.minimumChartHeight)
  ```

- 背景柱绘图区继续固定高度，但改为消费契约：

  ```swift
  .frame(height: SevenDayBarChartLayoutContract.plotHeight)
  ```

- `barHeight(for:)` 的比例上限也必须消费同一个 `plotHeight`，保持 `words / maxWords * 92` 的原语义；零值返回 8、非零最小 12 的规则保持不变。
- 不给词数或星期 label 增加新的固定最大高度，不使用 `clipped()`、`fixedSize`、`minimumScaleFactor` 或手工字号压缩掩盖 Dynamic Type 问题。
- 星期 label 的现有 `.lineLimit(1)`、字体、颜色保持不变；辅助功能列宽负责减少横向压缩。

### 4. 视觉与行为保留

必须保持：

- `HStack(alignment: .bottom, spacing: 9)`、day column `VStack(spacing: 7)`。
- 词数和星期的现有语义字体及 secondary 样式。
- 背景柱与数据柱的颜色、空值透明度、5pt 圆角。
- `day.wordCount == 0 ? "" : ...` 的显示规则。
- `barHeight(for:)` 对 0、最小非零柱高、最大柱高和相对比例的既有结果。
- `stats.lastSevenDays`、`stats.maxDailyWordCount` 的传参和统计区块结构。
- 普通字号下的现有七列等分宽视觉，不因引入契约而固定为 56pt。

本轮不要加入可见辅助说明、滚动提示、分页指示器、动画或新的卡片层级。

## 人工 UI 风险

- 56pt 列宽是为辅助功能字号提供的稳定基线，但不同语言、极端词数位数和最大 Accessibility 字号仍可能需要更宽列；需在真实 iPhone/iPad/Mac Catalyst 上观察。
- 水平 ScrollView 解决强制压缩，但滚动可发现性、触控回弹、Mac 触控板/鼠标滚轮方向与键盘/VoiceOver 导航仍需人工操作。
- 普通字号路径有源码与契约回归边界，但没有视觉 snapshot，仍需人工确认七列等分和间距未出现像素级回归。
- `minimumChartHeight` 允许内容增高，不保证所有系统字体、locale 和可用宽度组合绝无裁切；云端 build 与纯 XCTest 不能替代渲染验收。
- 本轮不改统计计算和写入性能；既有预计算、按需排序、Store 节流与 JSON 保存只作为不得回归边界，不能宣称 v0.71 新增了写入性能优化。
