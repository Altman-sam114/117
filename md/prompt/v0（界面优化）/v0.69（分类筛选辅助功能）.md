`v0.69`

## 版本分配依据

- `v0.68` 已完成 Mac Catalyst 较新/较早日记键盘导航；Agent X 后续审计确认列表分类筛选 chip 仍未达到 iOS 最低 `44pt` 点击高度，且选中状态仍主要依赖颜色、未向 VoiceOver 暴露 `.isSelected`。

## 背景与现状

`MDJournal/Views/EntryListView.swift` 的 `CategoryFilterChip` 当前具备：

- `Button` 语义和 `.buttonStyle(.plain)`；
- 分类图标、标题和数量；
- `footnote` / `caption` Dynamic Type 字体；
- 选中背景、描边和 tint；
- 水平滚动及 `HStack(spacing: 8)`；
- `selectedCategory` 驱动的“全部”与具体分类筛选。

但当前 chip 只有上下各 `8pt` padding，没有明确 `44pt` 最小交互高度；选中与未选中主要依赖 tint、背景和描边区分；VoiceOver 没有 `.isSelected` trait；视觉上也没有不依赖颜色的选中标记。SwiftUI 设计规则要求 iOS 交互区域至少 `44×44pt`，同时应避免固定高度妨碍 Dynamic Type。辅助功能规则要求重要状态不能只依赖颜色，装饰图像应从 VoiceOver 隐藏。

现有 `JournalEntryListSnapshotTests` 已覆盖搜索、分类计数、筛选顺序和空结果，但它不渲染 SwiftUI，也不能直接证明 hit testing、frame 或 VoiceOver trait。本轮不得以读取 `EntryListView.swift` 源码并匹配 modifier 字符串的方式伪造布局测试。

## 本轮目标

1. 分类筛选 chip 的 Button label 至少具有 `44pt` 可点击高度。
2. 使用 `minHeight` 而不是固定 `height`，保留现有语义字体和垂直 padding，使内容随 Dynamic Type 自然增高，不裁剪标题、计数、分类图标或勾选。
3. 在最终 label 尺寸建立后添加矩形 `.contentShape(Rectangle())`，让完整 chip 矩形参与 Button 命中。
4. 选中 chip 向 VoiceOver 暴露 `.isSelected`；未选中 chip 不带该 trait。
5. 添加可见 `checkmark` 作为不依赖颜色的选中标记。
6. 未选中状态保留与勾选相同宽度的布局槽位，避免选择切换时 chip 自身宽度和后续横向布局跳动。
7. 勾选是装饰性状态重复表达，必须 `.accessibilityHidden(true)`，避免 VoiceOver 重复朗读“勾选”。
8. 保持原分类图标、标题、计数、横向滚动、筛选状态流、间距、圆角、颜色主题和列表结构。
9. 将 GitHub Actions 结果包版本更新为 `v0.69`，同步受影响文档，并由 Agent C 下载最新未加密 artifact 复判。

## UI 契约设计

### 极小可测契约

在 `EntryListView.swift` 中定义内部可见的无状态契约，例如：

```swift
enum CategoryFilterChipContract {
    static let minimumInteractiveHeight: CGFloat = 44

    static func accessibilityLabel(title: String, count: Int) -> String {
        "\(title)，\(count) 篇"
    }
}
```

要求：

- 类型不得声明为 `private`，以便现有 test target 通过 `@testable import MDJournal` 测试；也不得公开为 `public` API。
- `minimumInteractiveHeight` 必须由 chip 的 `.frame(minHeight:)` 直接消费，不能只为测试存在。
- accessibility label helper 必须由 Button 的 `.accessibilityLabel(...)` 直接消费，不能在视图里另写一份字符串。
- 文案保持可理解的标题和计数，并给计数加“篇”语境；至少覆盖“全部”和一个具体分类、`0` 与复数计数。
- 不把颜色、圆角、padding 或其他一次性样式全部搬入契约，不建立过度抽象。

### 稳定勾选槽位

`CategoryFilterChip` 使用一个始终存在的 `Image(systemName: "checkmark")`：

- 选中时可见，未选中时用 `.opacity(0)` 保留布局，不使用条件 `if isSelected` 插入/移除图像。
- 图像使用现有语义字体体系，例如 `.font(.caption.weight(.bold))`，不得使用不随 Dynamic Type 缩放的硬编码 `.system(size:)`。
- 为避免切换时槽位宽度变化，同时避免辅助功能字号裁剪，使用 `@ScaledMetric(relativeTo: .footnote)` 定义一个小的 selection indicator 宽度，并用 `.frame(width:)` 建立固定于当前 Dynamic Type category、可随 category 缩放的槽位。
- 槽位只固定宽度，不固定 chip 总宽度或总高度；不同标题和计数仍可有各自自然宽度。
- 图像始终 `.accessibilityHidden(true)`；VoiceOver 的选中状态由 Button 的 `.isSelected` trait 表达。

### 精确 label 结构与 modifier 顺序

将当前 Button label 的单个 `Label` 改为承载原 `Label` 与勾选槽位的 `HStack`。必须遵循以下结构和顺序：

```swift
Button(action: action) {
    HStack(spacing: 6) {
        Label {
            Text("\(title) \(count)")
                .font(.footnote.weight(.semibold))
        } icon: {
            Image(systemName: systemImage)
                .font(.caption.weight(.bold))
        }

        Image(systemName: "checkmark")
            .font(.caption.weight(.bold))
            .frame(width: selectionIndicatorWidth)
            .opacity(isSelected ? 1 : 0)
            .accessibilityHidden(true)
    }
    .lineLimit(1)
    .padding(.horizontal, 12)
    .padding(.vertical, 8)
    .frame(minHeight: CategoryFilterChipContract.minimumInteractiveHeight)
    .contentShape(Rectangle())
    .background(
        isSelected ? tint.opacity(0.18) : Color(.secondarySystemGroupedBackground),
        in: RoundedRectangle(cornerRadius: 8)
    )
    .overlay(
        RoundedRectangle(cornerRadius: 8)
            .stroke(isSelected ? tint.opacity(0.55) : Color.clear, lineWidth: 1)
    )
}
.buttonStyle(.plain)
.foregroundStyle(isSelected ? tint : .secondary)
.accessibilityLabel(CategoryFilterChipContract.accessibilityLabel(title: title, count: count))
.accessibilityAddTraits(isSelected ? .isSelected : [])
```

此代码用于约束结构和 modifier 顺序，Agent B 可按编译需要做不改变语义的格式调整。关键约束：

1. 原分类 `Label` 的标题、计数、图标和字体不变。
2. 勾选必须始终占位，顺序位于原 Label 之后，并与原内容处于同一 `HStack`。
3. `lineLimit`、padding 先建立内容；`.frame(minHeight:)` 在 padding 之后，只设最小高度。
4. `.contentShape(Rectangle())` 必须紧跟最终 `minHeight` frame，不能放在 frame 之前。
5. 背景和描边应用于已完成最小高度与命中形状的 label，不得只放大背景而未扩大 Button label。
6. Button 外继续先使用 `.buttonStyle(.plain)` 和现有 `.foregroundStyle(...)`，随后添加显式 accessibility label 与条件 `.isSelected` trait。
7. 不给未选中状态添加错误的 `.isSelected`，不使用仅靠 `accessibilityValue("已选择")` 代替 trait。
8. 不删除现有视觉选中 tint / 背景 / 描边；checkmark 是额外的非颜色信号。

## 风险

- 增加勾选槽位会让每个 chip 略宽，同一屏可见数量可能减少；现有水平滚动用于承载，不应通过缩小文字、间距或点击区抵消。
- `minHeight: 44` 会让筛选栏比当前略高；这是满足交互尺寸的预期变化，不能通过减少垂直 padding 使视觉内容拥挤。
- 极端 Dynamic Type 下 chip 会自然增高并可能更宽，横向滚动长度增加；本轮优先保证不裁剪和可操作，不强制把所有 chip 塞入一屏。
- `.opacity(0)` 保留布局但仍创建图像视图；数量只有固定分类集合，成本可忽略。必须配合 `.accessibilityHidden(true)` 防止不可见装饰进入 accessibility tree。
- 单元测试无法检查 SwiftUI 最终 layout、hit testing 或 accessibility tree；真实 iPhone/iPad/Mac Catalyst 命中、VoiceOver 朗读和切换视觉仍需人工验证。

## 禁止项

- 禁止用固定 `.frame(height: 44)`、`maxHeight: 44` 或压缩字体实现最小高度。
- 禁止把 `.contentShape(Rectangle())` 放在最终 `minHeight` frame 前，或只扩大背景而不扩大 Button label。
- 禁止用 `if isSelected` 条件插入/删除 checkmark，或不给未选中状态保留同宽槽位。
- 禁止使用固定像素字体绘制勾选，禁止固定 chip 总宽度，禁止让槽位在同一 Dynamic Type category 下随 selection 改变。
- 禁止让装饰 checkmark 被 VoiceOver 单独读取，禁止只靠颜色表达选中，禁止以 accessibility value 替代 `.isSelected` trait。
- 禁止删除或改写原分类图标、标题、计数、横向滚动、8pt 间距、筛选 action、配色、背景和描边。
- 禁止通过 `rg`/正则/源码字符串 XCTest 冒充布局、modifier 或 VoiceOver 验证。
- 禁止新增 UI test target、第三方依赖、新持久化字段、服务器、账号或云同步。
- 禁止改 Xcode target/deployment target、`JournalStore`、`JournalEntry`、Markdown、编辑器或 JSON。
- 禁止本机 build、XCTest、模拟器或 app；禁止用本地输出冒充云端 artifact。
- 禁止创建候选分支或 PR，禁止跳过 Agent C 对最新 `origin/main` artifact 的验收。
