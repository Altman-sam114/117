# MD Journal 支持

MD Journal 是在设备上保存 Markdown 日记的原生应用。可以在应用的“设置”中查看隐私政策、启用应用锁、导出 JSON 备份、合并导入备份，以及管理可选的 Pro 订阅。

## 日记与备份

- 日记默认保存在应用私有目录。建议定期把 JSON 备份保存到你信任的位置。
- 导入先校验并显示预览，经确认仅追加新 ID。冲突内容保留本地版本，避免覆盖。
- 如看到“读取本地日记失败”，不要卸载应用。先在设置中导出原始文件保留副本，再尝试重新读取；保护状态不会因为关闭提示而解除。
- 系统 iCloud 设备备份可能包含日记；这与应用的主动导出、日记云同步是不同机制。

## 应用锁

应用锁由设备身份认证处理。Face ID 或 Touch ID 无法使用时，系统可以提供设备密码验证。请先在系统中设置设备密码。应用锁不会另设一个开发者可重置的密码；开发者无法替你解锁设备或恢复未备份的数据。

## Pro 订阅

高级功能包括按日期和分类筛选的批量 Markdown 与分页 PDF 导出。基础日记编辑、单篇分享、统计和 JSON 备份不要求订阅。

购买使用 Apple 系统确认页。商店暂时不可用、商品尚未配置或交易等待批准时，不会显示伪造的成功状态。更换设备后可使用相同 Apple 账号恢复购买；日记文件需另用系统备份或 JSON 备份迁移。

可在[Apple 订阅管理](https://apps.apple.com/account/subscriptions)查看或取消自动续期。退款请使用 [Apple 报告问题](https://reportaproblem.apple.com/)。取消订阅或卸载应用不等同于退款。
