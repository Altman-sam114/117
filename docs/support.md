# MD Journal 支持

MD Journal 是在设备上保存 Markdown 日记的原生应用。可以在应用的“设置”中查看隐私政策、启用应用锁、导出 JSON 备份、合并导入备份，以及管理可选的 Pro 订阅。

## 写作与保存

- “外观与写作”可选择浅色/深色/跟随系统、正文字体、字号和行距，编辑与预览共用偏好并适配系统辅助字号。这些设置免费，恢复默认不会更改日记、应用锁或订阅。
- “正在保存”表示最新修改尚待写盘；只有当前修改的写入确认返回后才显示“已存到本机”。如显示“保存失败”，请勿卸载应用，可重试保存，必要时先导出当前 JSON 备份。关闭错误提示不会把失败变成成功。

## 日记与备份

- 日记默认保存在应用私有目录。建议定期把 JSON 备份保存到你信任的位置。
- 导入先校验并显示预览，经确认仅追加新 ID。冲突内容保留本地版本，避免覆盖。单次导入上限为 25 MiB、10,000 篇；完整导出不截断，超过上限的备份需先在电脑上拆分为合法 JSON 数组再分批导入，请保留原始完整副本。
- 如看到“读取本地日记失败”，不要卸载应用。先在设置中导出原始文件保留副本，再尝试重新读取；保护状态不会因为关闭提示而解除。
- 系统 iCloud 设备备份可能包含日记；这与应用的主动导出、日记云同步是不同机制。

## 应用锁

默认的“隐藏多任务预览”会在离开应用时遮挡内容，包括已经打开的设置或其他页面，返回时不要求身份验证；你可以在设置关闭。它与应用锁独立，开启应用锁时始终遮挡非活跃窗口。这不能阻止主动截屏、录屏或分享。

应用锁由设备身份认证处理。Face ID 或 Touch ID 无法使用时，系统可以提供设备密码验证。请先在系统中设置设备密码。应用锁不会另设一个开发者可重置的密码；开发者无法替你解锁设备或恢复未备份的数据。

## Pro 订阅

高级功能包括按日期和分类筛选的批量 Markdown 与分页 PDF 导出。PDF 可添加私人日记集封面，显示自定义名称、日期范围与篇数；名称最多 80 个字符，完整日记原文不截断。PDF 保留原始 Markdown 文本，不冒充富文本排版器。基础日记编辑、外观与排版偏好、单篇分享、统计、应用锁和 JSON 备份不要求订阅。

购买使用 Apple 系统确认页。商店暂时不可用、商品尚未配置或交易等待批准时，不会显示伪造的成功状态。更换设备后可使用相同 Apple 账号恢复购买；日记文件需另用系统备份或 JSON 备份迁移。

可在[Apple 订阅管理](https://apps.apple.com/account/subscriptions)查看或取消自动续期。退款请使用 [Apple 报告问题](https://reportaproblem.apple.com/)。取消订阅或卸载应用不等同于退款。
