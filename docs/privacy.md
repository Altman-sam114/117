# MD Journal 隐私政策

生效日期：2026 年 10 月 24 日。

本政策适用于 MD Journal 的 iOS、iPadOS 和 Mac Catalyst 应用。开发者联系入口见[支持页面](support.md)。

## 日记与本机存储

日记标题、正文、日期、分类和心情保存在应用私有目录的本地 JSON 文件中。应用没有自建服务器、注册账号、日记云同步、广告或第三方统计 SDK，不会将日记上传给开发者，也不会出售或使用日记训练模型。

在 iPhone 和 iPad 上，日记文件使用系统的数据保护机制，采用设备首次解锁后可访问的保护等级，以兼顾系统锁屏与保存任务。保护效果依赖设备的系统安全设置。这不是应用自行实现的密码加密，也不是端到端加密服务。

系统设备备份可能包含本机日记，包括你在系统中启用的 iCloud 设备备份。备份的开启、保留和恢复由你与操作系统控制；应用没有另外建立日记同步服务。“本机存储”表示应用保存位置，不表示系统备份一定关闭。

## 导入、导出和分享

只有你主动执行导入、备份、Markdown/PDF 导出或系统分享时，数据才会交给你选择的文件位置或应用。你可以选择本机、iCloud Drive 或其他第三方目的地。这些目的地的隐私和安全由对应服务的政策决定。导出的文件包含可读日记，请妥善保管。

JSON 导入先校验文件并展示合并结果，经你确认后仅追加新的日记；与现有 ID 冲突的内容不会静默覆盖。读取失败的原始本地文件进入保护状态，不能通过新建日记覆盖它。

## 应用锁与生物识别

可选应用锁通过系统的设备所有者身份验证使用 Face ID、Touch ID 或设备密码。应用只接收认证成功或失败，不读取、存储或传输面容、指纹或设备密码。应用锁用于限制界面访问，并在离开应用时遮挡内容；它不能替代设备密码，也不能防止你主动截屏或导出数据。

## 设置与系统 API

应用使用 UserDefaults 保存本应用的偏好，例如是否启用应用锁。不会读取其他应用的设置，不使用跨应用跟踪标识符。随应用提供的 PrivacyInfo.xcprivacy 声明了这一用途。

## 订阅与购买

可选 MD Journal Pro 自动续期订阅由 Apple App Store 和 StoreKit 处理。应用使用 Apple 验证的交易与订阅状态在设备上判断高级功能权限，恢复购买也通过 Apple 进行。开发者不接收你的支付卡资料，不建立自有购买账号或交易服务器。

Apple 为提供商店、支付、退款和反欺诈服务处理的数据适用 [Apple 隐私政策](https://www.apple.com/legal/privacy/)。订阅价格、周期和可购买状态以应用内 Apple 返回的商品信息及系统购买确认页为准。删除应用不会自动取消订阅；请在 Apple 的订阅管理中取消。

## 保留、删除与支持

你可以删除单篇日记，或删除应用以移除该设备上的应用数据。你另行导出的文件和系统备份需要在相应位置管理。应用没有服务器端日记副本，因此开发者无法找回未备份的日记。取消订阅不会删除日记或锁住已有的免费编辑与 JSON 备份功能。

应用不会自动上传诊断日志。主动联系支持时，请只提供复现步骤、系统版本和经过隐去敏感信息的截图，不要在公开问题区提交日记、备份、支付凭证或个人身份信息。Apple 自身的崩溃报告、购买记录和系统备份设置由 Apple 的政策与系统选项管理。

## 政策更新

如应用的数据处理方式改变，本政策会随版本更新。新的数据收集或权限用途会在实际引入前明确说明。任何疑问均可通过[支持页面](support.md)联系项目维护者。
